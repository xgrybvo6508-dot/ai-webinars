Claude Tag — это Claude Code remote внутри Slack. Агентом может управлять любой участник канала. Kevin Martin выстраивает линию: чат в 2023-м, Claude Code в 2025-м, Cowork для неразработчиков и теперь Tag. Под капотом везде один harness, но меняется способ работы. Раньше человек сидел у Claude «за плечом» и рулил. Теперь он делегирует ему категорию работы по шаблону «всякий раз, когда X, делай Y», где X — событие в Slack. Это стало возможно только с ростом интеллекта моделей. По умолчанию спикер советует Opus 5.5.

> Не задача, а постоянная обязанность: срок, триггер, действие, границы, финал.

***

Демо выглядит как ночной кошмар дежурного, только без кошмара. Срабатывает пейджер, и, пока человек трёт глаза, Claude уже знает, когда вырос процент ошибок. Он снимает метрики, сравнивает последние деплои, проверяет feature flag, перезапускает тесты и называет первопричину. Затем предлагает два варианта исправления и рекомендует один: изменение конфигурации в четыре строки. PR он открывает под своей идентичностью со ссылкой на тред. После одобрения человеком следит за деплоем и метриками, сам закрывает инцидент и пишет черновик постмортема с таймлайном и follow-up задачами. Человек участвовал дважды: выбрал вариант и одобрил изменение.

***

Чтобы агент работал как член команды SRE, его оснащают как сотрудника. Ему нужны свои сервисные аккаунты с ограниченными хостами и методами, подключённые репозитории, skills и память канала. Он сам входит в каналы по префиксу имени, а в приватные — только по приглашению. Расходы под его идентичностью списываются на организацию, лимиты задаются для организации и для каждого канала. Обращаться с ним советуют как с коллегой: спросить «к чему у тебя есть доступ?» или поправить «KPI в постмортеме ставь наверх». Он это запомнит. Что взять себе: учись формулировать для своих ботов постоянные обязанности (срок, триггер, действие, границы, завершение). Учебный проект — бот, который по падению сайта собирает логи, предлагает фикс и пишет постмортем.
