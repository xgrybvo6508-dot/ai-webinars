# Вебинары AI — сайт саммари

Статический сайт без фреймворка: `node build.mjs` собирает `content/` в `dist/`.

    npm install && npm run build && npm run preview   # http://localhost:4400

## Как добавить вебинар (для бота)
Положить файл `content/webinars/ГГГГ-slug.md`, где имя файла станет URL `/w/ГГГГ-slug/`:

```md
---
title: "Название вебинара"
company: anthropic        # anthropic | openai | google | meta | cursor | other
date: 2026-08-11          # ГГГГ-ММ-ДД
tags: [агенты, data]      # промптинг, кодинг, enterprise, ...
speaker: Имя, роль
duration: 55 мин
source: https://ссылка-на-запись
source_label: Запись на YouTube · 26 мин   # подпись ссылки в конце статьи
lead: Одна фраза для карточки и под заголовком.
---

Первый абзац — суть. Первая буква станет буквицей, первая строка — капителью.

::fig integration-context "Подпись под иллюстрацией"

> Короткая сильная мысль станет выносной цитатой.

***
(*** ставит орнамент-разделитель вместо заголовка; первая строка следующего абзаца — капитель)
```

Текст пишется связной прозой, как глава книги, без заголовков `##`. Порядок мысли такой: суть → ключевые идеи → инсайты → как применить. Источник выводится в конце автоматически, из `source`.
Иллюстрации: строка `::fig имя "подпись"` вставляет `content/figures/имя.svg`. Это минималистичная линейная графика: штрихи с `class="d" pathLength="1"` прорисовываются при прокрутке, подписи задаются через `<text class="t">`. Цвета: #6b7cff, #d97757, #2fd6c3, #a3abba.
Ближайшие вебинары лежат в `content/upcoming.json`: поля title, company, datetime (ISO с +03:00), label.

## Деплой на GitHub Pages
Все ссылки относительные, поэтому сайт работает из любой подпапки (`user.github.io/repo/`).
1. Создать репозиторий и запушить проект.
2. Settings → Pages → Source: GitHub Actions; workflow `.github/workflows/pages.yml` уже в проекте.
